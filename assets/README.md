# Assets

The railway, minecart, geological contours, diamonds and stylised Golden Record are original vector drawings embedded in index.html or styles.css. No downloaded image assets or third-party artwork are required. The disc recalls the historical Voyager record discussed in NASA reference [12]; it is not a technical replica.

Display font stack: Georgia Pro Light, Georgia Pro, Georgia, serif.
Body font stack: Segoe UI, Arial, sans-serif.

Fonts are used from the viewer's operating system and are not redistributed. All slide artwork and diagrams work offline.
